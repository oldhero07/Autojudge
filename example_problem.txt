Problem: Maximum Subarray Sum (Kadane's Algorithm)

Given an array of integers, find the contiguous subarray with the largest sum and return its sum.

Input Format:
- First line contains an integer n (1 ≤ n ≤ 10^5)
- Second line contains n space-separated integers (-10^9 ≤ arr[i] ≤ 10^9)

Output Format:
- Print a single integer representing the maximum sum of any contiguous subarray

Constraints:
- 1 ≤ n ≤ 100,000
- -1,000,000,000 ≤ arr[i] ≤ 1,000,000,000

Example:
Input:
5
-2 1 -3 4 5

Output:
9

Explanation: The subarray [4, 5] has the maximum sum of 9.

This problem can be solved using Kadane's algorithm with dynamic programming approach in O(n) time complexity. It's a classic medium-difficulty problem that tests understanding of dynamic programming and optimal subarray algorithms.

Expected Difficulty: Medium (around 5-6/10)
Keywords: dynamic programming, algorithm, optimize, maximum
